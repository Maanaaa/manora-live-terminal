# ADR 0004 — CI GitHub Actions

- Statut : accepté
- Date : 2026-11-12

## Décision

Même CI que les autres dépôts Manora Live : lint ESLint, `tsc --noEmit`, tests `node --test` avec rapport JUnit, build de l'image Docker, OSV-Scanner (non bloquant), gitleaks, Sonar si le secret `SONAR_TOKEN` existe.

Pas de déploiement automatique : le Pi n'est pas joignable depuis GitHub. Mise à jour à la main sur le Pi (voir README).
